# Hyperion, Unfinished

A small site for finishing what Keats couldn't: both *Hyperion: A Fragment*
(breaks off mid-line at Book III, line 136 — the editor re-opens that line,
preloading Keats' hanging "Celestial") and *The Fall of Hyperion: A Dream*
(breaks off at Canto II, line 61), each followed by a ruled, numbered blank
space where the visitor writes their own continuation.

Drafts autosave to `localStorage` and can be downloaded / re-imported as
`.json`. Finished endings can be **published to a public gallery** —
anonymous, no accounts: a free-text pen name is asked for, and entries left
blank are bylined "Writ in water", after Keats' epitaph.

## Layout

- `public/` — the whole deployable site (static; no build step).
  - `index.html`, `styles.css`, `app.js`
  - `config.js` — Supabase URL + anon public key for the gallery. Safe to
    commit: the anon key is public by design, and Row Level Security only
    lets it insert entries and read visible ones. The service_role key and
    database password must never enter this repo.
  - `poems.json` — the two poems, generated by the scraper
  - `fonts/` — self-hosted IM Fell English (SIL OFL)
- `scripts/scrape_poems.py` — deterministic scraper for keats-poems.com;
  strips the site's printed margin numbers and editorial matter, validates
  line counts against canonical totals (357 / 391 / 136 / 468 / 61).
- `data/raw/` — cached page HTML so re-runs are reproducible offline.

## Develop

```bash
uv sync                          # set up the (stdlib-only) Python env
uv run scripts/scrape_poems.py   # regenerate public/poems.json
python3 -m http.server -d public 8000   # local preview
```

## Deploy

The repo is Vercel-ready: `vercel.json` points the deployment at `public/`
with no build command. Just run `vercel` (or connect the repo) — nothing
outside `public/` is uploaded.

## Notes

- Continuation targets default to ~800 lines for *Hyperion* (about the size
  of the two finished books together) and ~400 for *The Fall* (about one
  finished canto); both are adjustable in the UI.
- The editor's syllable counter is a heuristic, not a scansion engine: it
  counts vowel groups with corrections for silent -e, silent -ed, and
  elisions like "pluck'd". It's exact on most lines and off by one on words
  like *quiet* or *fiery* (adjacent vowels that are really two syllables) and
  on proper nouns — hence the `~`. Treat it as a nudge toward pentameter,
  not a verdict; blank verse legitimately runs 9–11 anyway.
- The gallery is backed by Supabase (Postgres + RLS), reached with plain
  `fetch` — no client library. Spam dampening: DB length constraints, a
  10-minute client cooldown, and a honeypot field. Moderation happens in the
  Supabase dashboard (toggle `hidden` or delete the row); the anon key
  cannot edit or delete anything.
- Text source: [keats-poems.com](http://keats-poems.com/) — public domain.
