# Hyperion, Unfinished

A small site for finishing what Keats couldn't: both *Hyperion: A Fragment*
(breaks off at Book III, line 136) and *The Fall of Hyperion: A Dream*
(breaks off at Canto II, line 61), each followed by a ruled, numbered blank
space where the visitor writes their own continuation.

MVP scope: single user. Drafts autosave to `localStorage` and can be
downloaded / re-imported as `.json`.

## Layout

- `public/` — the whole deployable site (static; no build step).
  - `index.html`, `styles.css`, `app.js`
  - `poems.json` — the two poems, generated by the scraper
  - `fonts/` — self-hosted IM Fell English (SIL OFL)
- `scripts/scrape_poems.py` — deterministic scraper for keats-poems.com;
  strips the site's printed margin numbers and editorial matter, validates
  line counts against canonical totals (357 / 391 / 136 / 468 / 61).
- `data/raw/` — cached page HTML so re-runs are reproducible offline.

## Develop

```bash
uv sync                          # set up the (stdlib-only) Python env
uv run scripts/scrape_poems.py   # regenerate public/poems.json
python3 -m http.server -d public 8000   # local preview
```

## Deploy

The repo is Vercel-ready: `vercel.json` points the deployment at `public/`
with no build command. Just run `vercel` (or connect the repo) — nothing
outside `public/` is uploaded.

## Notes

- Continuation targets default to ~800 lines for *Hyperion* (about the size
  of the two finished books together) and ~400 for *The Fall* (about one
  finished canto); both are adjustable in the UI.
- Text source: [keats-poems.com](http://keats-poems.com/) — public domain.
